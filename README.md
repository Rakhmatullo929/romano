# Romano Bot ☕

Telegram-бот для управления кофейней Romano.uz

## 📋 Описание

Romano Bot - это система управления для кофейни с ролевой системой авторизации, которая позволяет:
- 👥 **Управление пользователями** - роли администратора и бариста
- 💰 **Управление продажами** с поддержкой скидок
- 💸 **Отслеживание расходов** по категориям
- 📊 **Генерация отчетов** (только для администраторов)
- 💰 **Контроль баланса** и прибыльности
- 📥 **Экспорт данных** в CSV формате

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка окружения

Создайте файл `.env` в корне проекта (опционально):

```env
BOT_TOKEN=your_bot_token_here
ADMIN_IDS=123456789,987654321
DATABASE_URL=sqlite:///romano_bot.db
```

**Примечание:** Токен бота уже настроен в `config.py`. Переменные окружения имеют приоритет.

### 3. Создание первого администратора

```bash
python create_admin.py
```

### 4. Запуск бота

```bash
python run_bot.py
```

**Важно:** Бот защищен от запуска нескольких экземпляров. Если бот уже запущен, вы увидите сообщение об ошибке.

### 5. Остановка бота

```bash
python stop_bot.py
```

Скрипт безопасно остановит все экземпляры бота.

## 💰 Функциональность

### 👥 Система авторизации
- **Роли пользователей**: Администратор и Бариста
- **Регистрация**: Самостоятельная регистрация новых пользователей
- **Управление**: Администраторы могут добавлять/удалять пользователей
- **Активация**: Администраторы активируют новых пользователей
- **Права доступа**: Разные уровни доступа для разных ролей

### 💰 Продажи (Бариста + Администратор)
- Выбор из 5 продуктов (Американо, Капучино, Латте, Чай, Десерт)
- Настройка количества и скидок
- Выбор способа оплаты
- Автоматический расчет итоговой суммы

### 💸 Расходы (Бариста + Администратор)
- **Закуп** - закупка ингредиентов и товаров
- **Зарплата** - выплата зарплаты сотрудникам
- **Списание** - списание испорченных товаров

### 📊 Отчеты (Только Администратор)
- Дневные, недельные и месячные отчеты
- Детальная аналитика по продуктам и категориям
- Экспорт в CSV формат
- Расчет прибыли и убытков

### 💰 Баланс (Все пользователи)
- Отображение текущего состояния по периодам
- Выбор периода (день/неделя/месяц)
- Детальная статистика доходов и расходов

## 🔧 Технологии

- **Python 3.8+**
- **python-telegram-bot v20+** - Telegram Bot API
- **SQLAlchemy** - ORM для работы с БД
- **Pandas** - генерация CSV отчетов
- **SQLite** - база данных (по умолчанию)

## 📊 Логирование

Все действия логируются в файл `logs/bot.log`:
- Действия пользователей
- Ошибки и предупреждения
- Запуск и остановка бота
- Операции с базой данных

## 🛡️ Безопасность и авторизация

### Роли пользователей

#### 👑 Администратор
- **Управление пользователями**: Добавление, удаление, активация пользователей
- **Просмотр отчетов**: Доступ ко всем отчетам и аналитике
- **Управление ролями**: Изменение ролей пользователей
- **Все функции бариста**: Продажи, расходы, баланс

#### ☕ Бариста
- **Продажи**: Фиксация продаж с продуктами и скидками
- **Расходы**: Ввод расходов по категориям
- **Баланс**: Просмотр текущего состояния
- **Ограничения**: Нет доступа к отчетам и управлению пользователями

### Система безопасности
- **Ролевая авторизация**: Проверка прав доступа для каждой операции
- **Регистрация**: Контролируемая регистрация новых пользователей
- **Активация**: Администраторы активируют новых пользователей
- **Валидация данных**: Проверка всех входных данных
- **Логирование**: Отслеживание всех действий пользователей
- **Graceful shutdown**: Корректное завершение работы

## 📝 Использование

### Для новых пользователей
1. Запустите бота командой `/start`
2. Нажмите "📝 Зарегистрироваться" для создания аккаунта
3. Дождитесь активации администратором
4. После активации используйте меню для работы

### Для администраторов
1. Запустите бота командой `/start`
2. Используйте раздел "👥 Пользователи" для управления
3. Активируйте новых пользователей
4. Просматривайте отчеты и аналитику
5. Управляйте ролями пользователей

### Для бариста
1. Запустите бота командой `/start`
2. Используйте разделы "💰 Продажи" и "💸 Расходы"
3. Просматривайте баланс в разделе "💰 Баланс"
4. Обратитесь к администратору для доступа к отчетам

## 🔄 Graceful Shutdown

Бот поддерживает корректное завершение работы:
- Нажмите `Ctrl+C` для остановки
- Все данные сохраняются автоматически
- Логируется процесс завершения
