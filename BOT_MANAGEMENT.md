# Romano Bot - Управление ботом

## Запуск бота

Для запуска бота используйте:

```bash
python run_bot.py
```

Бот автоматически:
- Проверит, что не запущена другая копия
- Получит блокировку для предотвращения конфликтов
- Запустится и начнет обрабатывать сообщения

## Остановка бота

### Способ 1: Автоматическая остановка

Используйте скрипт для безопасной остановки всех экземпляров бота:

```bash
python stop_bot.py
```

Скрипт:
- Найдет все запущенные экземпляры бота
- Безопасно их остановит
- Очистит файл блокировки

### Способ 2: Ручная остановка

Остановите конкретный процесс по его PID:

```bash
# Найдите PID процесса
ps aux | grep run_bot.py

# Остановите процесс
kill <PID>
```

Или остановите все процессы бота:

```bash
pkill -f "run_bot.py"
```

## Решение проблемы "Bot already running"

Если вы видите ошибку:

```
❌ Ошибка: Бот уже запущен!
Пожалуйста, остановите существующий экземпляр бота перед запуском нового.
```

Это означает, что уже запущена копия бота. Для решения:

1. **Используйте скрипт остановки** (рекомендуется):
   ```bash
   python stop_bot.py
   ```

2. **Или остановите процессы вручную**:
   ```bash
   # Найти все процессы
   ps aux | grep run_bot.py
   
   # Остановить принудительно
   kill -9 <PID>
   
   # Удалить файл блокировки
   rm .bot.lock
   ```

3. **Затем перезапустите бота**:
   ```bash
   python run_bot.py
   ```

## Проверка статуса

Проверьте, запущен ли бот:

```bash
# Найти процессы бота
ps aux | grep run_bot.py | grep -v grep

# Посмотреть последние логи
tail -f logs/bot.log
```

## Особенности реализации

1. **Защита от множественных экземпляров**: Бот использует файловую блокировку (`.bot.lock`) для предотвращения одновременного запуска нескольких копий.

2. **Graceful shutdown**: При остановке бот корректно завершает работу, освобождая ресурсы и удаляя файл блокировки.

3. **Логирование**: Все события бота записываются в `logs/bot.log`.

## Устранение неполадок

### Бот не запускается

1. Проверьте логи: `tail -20 logs/bot.log`
2. Убедитесь, что нет других экземпляров: `ps aux | grep run_bot.py`
3. Очистите файл блокировки: `rm .bot.lock`
4. Проверьте конфигурацию бота

### Ошибка "Conflict: terminated by other getUpdates request"

Эта ошибка возникает, когда несколько экземпляров бота пытаются использовать один и тот же токен Telegram.

**Решение**:
1. Используйте `python stop_bot.py` для остановки всех экземпляров
2. Запустите бота снова: `python run_bot.py`

### Бот висит как "зомби" процесс

Если процессы бота зависли:

```bash
# Найти все процессы
ps aux | grep run_bot.py

# Принудительно завершить все
pkill -9 -f run_bot.py

# Удалить файл блокировки
rm -f .bot.lock

# Запустить заново
python run_bot.py
```
